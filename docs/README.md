# Скриншоты

`login.png`, `chat-desktop.png` и `chat-mobile.png` создаются сценариями Playwright:

```bash
npm run test:e2e
```

Все имена, номера, сообщения и реквизиты на скриншотах вымышлены. Данные из личного аккаунта MAX не использовались. Время и ответы API в браузерных сценариях фиксированы для воспроизводимого результата.
